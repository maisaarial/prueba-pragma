# Prueba práctica Analista de datos - María Isabel Aristizabal

Proyecto base para analisis de datos con Python.

## Crear el entorno virtual

En una terminal en la raiz del proyecto:

```
python -m venv .venv
```

## Activar el entorno

```
.\.venv\Scripts\Activate.ps1
```

## Instalar dependencias

Con el entorno activado:

```
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```
